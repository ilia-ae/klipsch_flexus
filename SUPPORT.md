# Support

## Where to ask

| What | Where |
| --- | --- |
| Questions about setup, dashboards or how something works | [GitHub Discussions](https://github.com/ilia-ae/klipsch_flexus/discussions) |
| Something does not work as described | [Bug report](https://github.com/ilia-ae/klipsch_flexus/issues/new?template=bug_report.yml) |
| An idea for a new feature | [Feature request](https://github.com/ilia-ae/klipsch_flexus/issues/new?template=feature_request.yml) |
| A security problem | Privately, as described in [SECURITY.md](SECURITY.md). Never in a public issue |

First check [Troubleshooting](README.md#troubleshooting) and [Known Limitations](README.md#known-limitations) in the README.

## What to include

- The integration version (HACS, or Settings > Devices & Services > Klipsch Flexus), and whether it is a stable or a beta release
- Your Home Assistant version (Settings > About)
- Your soundbar model (CORE 100, 200 or 300) and its firmware version (the Klipsch Connect Plus app, or **Firmware** on the device page in Home Assistant)
- What you did, what you expected and what happened
- Log lines that mention `klipsch_flexus` (Settings > System > Logs)
- The diagnostics file: Settings > Devices & Services > Klipsch Flexus > ⋮ > **Download diagnostics**. The integration redacts the IP address, every MAC address (including the signing MAC), the Wi-Fi BSSID, the device ID and stream URLs. Read the file before you post it anyway.
